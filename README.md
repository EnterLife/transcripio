# Transcripio

Простое локальное приложение для транскрибации аудио и видео. ASR работает через локальную
модель `faster-whisper`; если на вход подано видео, аудиодорожка извлекается через `ffmpeg`.
Распознавание участников подключается опционально через локально сохраненный пайплайн
`pyannote.audio`.

## План разработки

1. Базовый каркас проекта: UI, модуль извлечения аудио, модуль транскрибации, модуль
   диаризации, форматтеры результата.
2. Минимальный рабочий поток: загрузить аудио/видео, извлечь WAV, получить текст,
   скачать результат в TXT/SRT/JSON.
3. Локальные модели:
   - `faster-whisper` автоматически использует модель по имени или локальный путь;
   - для полностью офлайн-режима лучше заранее скачать модель и указать путь в UI.
4. Диаризация участников:
   - скачать/подготовить локальный pyannote pipeline;
   - указать путь к локальной папке/`config.yaml` в UI.
5. Дальше: очередь задач, прогресс по сегментам, редактирование результата, экспорт DOCX/VTT,
   сохранение истории обработок.

## Установка

Требуется Python 3.10+ и установленный `ffmpeg`, доступный из командной строки.

```powershell
.\setup.ps1
```

Скрипт создаст виртуальное окружение `.venv`, обновит `pip`, установит все зависимости из
единого `requirements.txt` и подключит локальный пакет проекта в editable-режиме.

Если нужно выполнить шаги вручную:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install -r requirements.txt
python -m pip install -e . --no-deps
```

## Запуск

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

## Локальные модели

В поле модели Whisper можно указать:

- имя модели `tiny`, `base`, `small`, `medium`, `large-v3`;
- путь к локальной модели в формате CTranslate2, например `models/whisper-large-v3-ct2`.

Для участников укажите путь к локальному pyannote pipeline, например:

```text
models/pyannote-speaker-diarization/config.yaml
```

Если путь не указан, приложение сделает обычную транскрибацию без участников.
